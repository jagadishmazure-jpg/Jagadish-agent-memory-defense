# Security policy

This is a synthetic, offline study project. It contains no real user
data, no credentials, and no live model calls.

- Report a security issue by opening a private vulnerability report on
  the repository (GitHub private vulnerability reporting).
- Do not include real personal data, tokens, or customer content in
  any report; describe the issue with synthetic examples only.
- The human gate exists precisely so that destructive recovery (purge,
  rollback) cannot run without a named-person, single-use, scoped,
  expiring approval. Any bypass of that gate is treated as a
  security defect.
